# Fase 1 hanya Senpi/OMO Native

Hook Senpi paling kaya (block keras, mutate args, ctx.ui.confirm native) dan OMO belum punya guard terpasang sama sekali, sementara OpenCode sudah menjalankan dua guard yang tumpang tindih. Adapter lain ditunda sampai Core dan Trash terbukti di satu harness. Alternatif yang ditolak: OpenCode dulu (hook lebih miskin, tumpang tindih dengan guard lama) dan multi-harness sekaligus (prematur).
